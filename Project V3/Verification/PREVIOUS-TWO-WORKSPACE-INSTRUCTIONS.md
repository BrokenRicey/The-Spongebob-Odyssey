# Project V3 — Texas Grid Analysis

This is one desktop application. Open **Start Texas Grid Analysis** or **Texas Grid Analysis\Texas Grid Analysis.exe**. Keep the entire application folder together. Python and a separate web browser are not required.

## Included in the application
- The Houston transmission map generated by houston_grid.py, with all 701 supplied route features, street background, voltage filters, and directory locations.
- Add, edit, move, remove, and undo route-attached loads.
- An explicit assumed simulation-bus selector for each mapped load.
- A connection from mapped loads to the V4 power-flow engine.
- Baseline and scenario comparison, line outages, load disconnections, demand sweeps, voltage and branch tables, run logs, and result export in Simulation & results.
- Native project Save/Open dialogs. One project JSON stores route loads and the simulation model/editor inputs. Recalculate after opening.

## Workflow
1. Click a colored Houston power line.
2. Enter the load name, demand, power factor, and onsite generation. Choose a **Simulation bus (assumed connection)** if you want to simulate it. Click **Add load to this line**.
3. To change the load, click its marker or Edit. Save changes after choosing a bus. Move picks another GIS line; it does not automatically change the assigned simulation bus.
4. Click **Run mapped loads in simulation** below the load list. This replaces the simulation model's load list with the mapped loads and runs a new baseline using the selected buses. It opens **Simulation & results** in the same application.
5. Use that tab for scenarios, comparison tables, and exports. The Houston map remains available in the first tab.
6. Use **Save project** in the application toolbar to save both map attachments and simulation inputs. **Open project** restores them. The simulation-only buttons retain support for older .gridstudy files.

## Current integration limits
The GIS source is geographic data, not a validated electrical network. The selected bus is an explicit study assumption. Simulations use the existing representative 18-bus network and V4 engine, not an inferred electrical model of all 701 geographic features. Results are shown in the simulation workspace; they are not presented as measured line capacities on GIS routes.

Mapped loads transfer into simulation when you click Run mapped loads. Scenario edits made in the simulation workspace do not automatically move or overwrite the map's baseline load definitions. Rerunning mapped loads creates a fresh baseline from the map values. Up to 200 mapped loads may be transferred per run.

Street tiles require internet access. Route geometry, load controls, the map library, and simulation run locally. Geographic routes remain usable when street tiles are unavailable. Fault and transient studies remain unavailable.
