# Project V4 source

See [../README.md](../README.md) for the current desktop workflow, model assumptions,
and verification commands. Run `python main.py` with the dependencies in
`requirements-desktop.txt`.

The application uses `map/editor_window.py`, `map/assets/editor.*`,
`simulation/editor.py`, and `simulation/houston.py`. The older browser app and
native V3 controls are retained for regression/reference and are not the V4 entry
point.
